# 建材智途 AI 接口使用示例

接口基地址与网站同源。正式登录由 Sites 平台提供，示例请求需在已登录会话中执行。不能通过自行填写用户身份头获得项目权限。写请求要求同源 Origin；浏览器 fetch 会自动提供。

## 读取项目与业务实体

```http
GET /api/projects?limit=30&offset=0
GET /api/projects/{projectId}
GET /api/projects/{projectId}/roads?limit=100&offset=0
GET /api/projects/{projectId}/tasks/{taskId}
```

项目响应包含 `version`、`role`、`workflowStatus` 和模型。列表响应提供 `items`、`total`、`limit`、`offset`、`nextOffset`；项目列表同时保留兼容字段 `projects`。

## 编辑道路并重新计算

```http
PATCH /api/projects/{projectId}/roads/R09
Content-Type: application/json
If-Match: "3"
Idempotency-Key: 3ec4adb7-f2f8-4fe6-9d44-6c41b841131b

{"closed":true}
```

成功后响应返回新的 `version`。后续操作必须使用新版本；不能继续发送旧的 `If-Match`。

```http
POST /api/projects/{projectId}/planning-runs
Content-Type: application/json
If-Match: "4"
Idempotency-Key: ca3de930-5c43-4a55-8c36-4fe84af9913a

{"taskId":"T01"}
```

成功返回计算记录 ID、输入版本、输入摘要、状态和计算结果。记录使用数据库中的模型，不采信请求提供的路线距离。示范路网关闭 R09 后，A 到 L 的路线由 100 m 变为 160 m。

## 新增任务

```http
POST /api/projects/{projectId}/tasks
Content-Type: application/json
If-Match: "4"
Idempotency-Key: 01a1fd3a-1afd-4b3a-a383-d10df0a205d0

{
  "name":"砌块配送",
  "material":"砌块",
  "start":"A",
  "end":"L",
  "trips":10,
  "width":2.2,
  "speed":1.2,
  "handling":4,
  "hourlyRate":120,
  "baseline":220,
  "windowStart":"08:00",
  "windowEnd":"09:30",
  "resource":"小型转运车 01"
}
```

编号 `id` 可省略，服务端在当前项目内分配。节点、道路、任务和堆场的引用必须属于同一项目；存在引用时不能直接删除节点。

## 成员权限

```http
POST /api/projects/{projectId}/members
Content-Type: application/json
Idempotency-Key: 08608568-bff0-44f0-8817-ab3232111f63

{"email":"member@example.com","role":"viewer"}
```

仅所有者可以管理成员。目标账号需先登录过本站；支持 `viewer` 和 `editor`。更新已有成员时使用同一接口及新的逻辑请求键。

## 复核和恢复

```http
POST /api/projects/{projectId}/submit
If-Match: "5"

POST /api/projects/{projectId}/approve
If-Match: "7"

GET /api/projects/{projectId}/versions?limit=30
POST /api/projects/{projectId}/versions/3/restore
If-Match: "8"

GET /api/projects/{projectId}/audit-events?limit=30
```

上面的版本数字是不同操作阶段的示意。实际应读取每次响应的新版本。提交和确认接口会检查当前业务规则及复核记录；历史恢复创建新版本，并清除原确认状态。

## 错误响应

```json
{
  "error":"云端版本已有变化，请重新载入",
  "code":"VERSION_CONFLICT",
  "requestId":"e89d6339-1808-4377-a8b2-77b9792f0753"
}
```

| 状态 | 含义 | 客户端处理 |
| --- | --- | --- |
| 400 | JSON、分页或请求键格式无效 | 修正请求 |
| 401 | 未登录 | 使用站点登录入口 |
| 403 | 角色或来源不允许 | 检查项目权限，从站点同源发起 |
| 404 | 项目、记录不存在或无访问权 | 重新读取项目列表 |
| 409 | 版本、幂等内容或流程状态冲突 | 保留本机草稿后重新载入，或另存新项目 |
| 413 | 超过正文、模型或底图限制 | 缩小文件或拆分项目 |
| 415 | 非 JSON 正文 | 设置 application/json |
| 422 | 业务字段、引用或工程规则不满足 | 按错误和 details 调整 |
| 428 | 缺少版本条件 | 读取当前版本并传 If-Match |
| 429 | 请求过频 | 根据 Retry-After 重试 |
| 503 | 依赖或服务暂不可用 | 保存草稿或备份，稍后重试 |

对同一逻辑请求重试，应复用相同 `Idempotency-Key`、正文和版本。新的编辑操作应生成新的键。完整接口目录见 `/api/openapi`。
