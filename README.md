# 芯护云 · 掌芯智护公开体验平台

访问地址：https://zhangxin-care-cloud.expertjam32.chatgpt.site

面向公众查阅与项目演示，无需注册。界面包含医护工作台和患者康复页，适配电脑、平板和手机。当前版本：1.1，更新于 2026-10-23。

## 建议体验顺序

1. 在患者管理新建一个使用昵称的体验档案，进入详情录入一条评估。
2. 在智能辅助生成方案草稿，填写审核代号和意见，确认体验方案。
3. 在训练中心加载方案，勾选说明，开始计时，结束后保存感受。
4. 在康复报告生成报告，检查记录，下载 TXT 或打印为 PDF。
5. 在肌电分析下载 CSV 模板，导入数据并查看实际计算结果。
6. 在设备管理建立绑定和维护记录，在我的康复创建提醒及沟通备忘。
7. 在数据与设置导出完整备份，以备换设备时手动导入。

## 数据与功能边界

- 网站可公开查阅；体验档案与记录保存在各访客自己的浏览器 localStorage 中，不跨访客共享。
- 无真实账户、身份鉴别或机构权限；医护与患者入口是体验视图切换。
- 示例患者均为虚构演示档案；不建议录入真实身份信息与敏感医疗数据。
- CSV 文件只在浏览器解析，不上传服务器。最大 5 MB，最多 50,000 个采样点。
- 波形质量提示采用启发式规则，不是医学异常识别模型。没有接入项目时序 AI 模型或外部大模型。
- 方案参数用于工作流演示，不是临床处方；体验审核不代表真实医师签署。
- 训练页不控制真实设备；在线、电量、固件等均明确标注为示例或本地资产记录。
- 沟通备忘不会发给真实医生。提醒仅在网页打开时检查，不发送短信或离线推送。
- 未归档训练会在当前浏览器保留草稿，刷新后暂停等待继续。网页隐藏、关闭后的时间不计入训练；浏览器存储不可用时无法保证草稿保留。
- 完整备份包含已保存的档案、训练、量表、报告、方案、留言和随访；训练草稿与最近恢复点独立保存在当前浏览器，迁移前请先将草稿结束归档。
- 浏览器清理、无痕模式或更换设备可能导致本地记录丢失。

这些边界也在网页中直接说明。附件提出的真实 AI 推理、设备控制和远程业务服务需要对应协议、服务和验证，不能从静态资料直接推断或伪造。

## 本地运行与部署

无需安装前端依赖。安装 Node.js 后，在解压目录运行：

```powershell
node serve.mjs
```

打开 `http://127.0.0.1:4173`。不要直接双击 index.html；浏览器会限制 file 协议下的 JavaScript 模块。

部署到其他静态托管服务时，把 `dist` 目录作为发布目录即可。导航采用哈希路由，不需要服务器重写。网站资源全部随包提供，没有运行时 CDN、字体或图标依赖。

## CSV 格式

```csv
time_ms,flexor_mv,extensor_mv
0,0.012,-0.005
1,0.018,0.003
2,0.009,0.007
```

UTF-8 编码。时间以毫秒计，非负且严格递增；两通道幅值以 mV 计。输入必须为有限数值，绝对幅值不超过 1000 mV。超过 5% 的采样间隔偏离会提示检查。记录未自动滤波，计算对应原始导入数据。

## 升级为真实业务平台所需接入

1. 用户与机构服务：身份认证、角色及患者授权、机构隔离、可靠数据库、备份和审计。
2. 设备协议：蓝牙服务 / 特征 UUID 或串口帧结构、网关地址、鉴权、通道映射、采样与校准关系、掉线和时间同步。
3. 硬件控制：物理参数单位及范围、安全互锁、急停与故障处理，完成真实硬件联调。
4. AI 服务：模型权重或安全推理 API、输入窗口与预处理、输出标签与置信度、适用人群和验证结果。密钥放在服务端。
5. 医患协同：真实消息通道、报告审核身份、随访推送与跨设备数据同步。

## 文件说明

- `dist/index.html`：网站入口。
- `dist/styles.css`：响应式视觉设计。
- `dist/app.js`：页面、交互、特征计算与图表。
- `dist/data.js`：示例数据、备份校验与内置知识。
- `dist/workflow.js`：训练草稿校验、时长计算、日历日期与 .ics 导出。
- `dist/downloads/xinhuyun-offline.html`：网页内可下载的完整离线单文件。
- `dist/assets/emg-prototype.jpg`：由所提供的项目 PDF 中提取的肌电采集原型照片。
- `serve.mjs`：只用于本地预览的静态服务器。

来源材料：用户提供的静态发布包、国创赛计划书 DOC、2026 年项目 PDF 及 PPTX。PPTX 主要为图片页面；功能规格以可提取的计划书正文与原有平台为依据。没有发布原始计划书、财务信息、个人联系方式或证件材料。

FMA 总分信息参考：University of Gothenburg, Fugl-Meyer Assessment，https://www.gu.se/en/neuroscience-physiology/fugl-meyer-assessment 。网页仅提供总分记录，不复制完整受使用条件约束的量表。
